# Projeto Olá

Este é um projeto de exemplo para praticar Git e versionamento de código.

## Descrição

Um site simples com HTML, CSS e JavaScript para aprender os fluxos de trabalho do Git.

## Estrutura do Projeto

- `pages/` - Arquivos HTML
- `css/` - Arquivos de estilo
- `js/` - Scripts JavaScript

## Como usar

1. Abra o arquivo `pages/oi.html` em um navegador
2. Explore as diferentes versões usando tags Git

## Versões

- `v0.0.0` - Primeiro commit
- `v1-beta` - Versão beta
- `v1` - Versão final
